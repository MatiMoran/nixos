Impacto del cap P95 de OLV — MLB

El cap P95 sube el BPP promedio observado porque bloquea una masa grande de prints que, en el escenario sin cap, tienen BPP relativamente bajo.

Conclusión: sacar el cap incorporaría 173.707 prints adicionales y reduciría el BPP promedio del mix de 19,87 a 16,95 (−14,71%). Al observar días con Budget similar en Looker, el completion rate se mantuvo similar mientras el CPM aumentó levemente.

Interpretación

El P95 no representa el 5% más caro del inventario global. Es el percentil 95 de cada curva lognormal de shading; por eso un contexto con una curva de precios baja puede quedar capeado aunque su precio monetario sea bajo frente al resto del inventario. El resultado es que se excluyen prints baratos, se reduce volumen y aumenta el BPP promedio del mix que permanece.

/* OLV cap p95 — impacto diario en CPM y prints perdidos, MLB
   Versión simplificada de wiki/olv_cpm_cap_counterfactual_reconstructed_mlb.sql:
   esa query reconstruía PRINT/LOSS desde cero (bid_auction_adx + adx_bid_feedback +
   MELIDATA.ADVERTISING) porque el ETL de BT_ADS_DSP_ADX_PRICING_RAW (job 293894)
   tenía un bug de regex que perdía las filas LOSS externas de OLV.

   Verificado (bq, ver conversación): ese fix ya está andando para datos recientes
   — BT_ADS_DSP_ADX_PRICING_RAW en MLB/VIDEO_OFF_ADX pasó de 100% print (bug) a
   ~9-13% print (tasa de ganancia real) a partir de EXECUTION_DATE = 2026-08-21.
   El 2026-08-23 (ayer) ya tiene datos completos: 8.692.271 prints / 86.717.869 losses.

   Por eso esta query puede usar BT_ADS_DSP_ADX_PRICING_RAW directo para PRINT/LOSS,
   FIRST_PRICE/SECOND_PRICE y BID_PRICE_PARTNER, y hace un LEFT JOIN liviano contra
   bid_auction_adx por BID_ID + LINE_ITEM_ID para traer shading_cap_percentile, optimal_win_rate
   y el fallback de parámetros de shading para losses (donde raw los deja NULL).
   — las dos columnas del cap p95 que NO existen en ningún punto del pipeline de
   BT_ADS_DSP_ADX_PRICING_RAW (confirmado leyendo el código del job 293894). No hace
   falta tocar adx_bid_feedback ni MELIDATA.ADVERTISING para nada.

   Complete bidder formula for capped bids:
   O = EXP(MU + SIGMA * qnorm(optimal_win_rate)) * SITE_INTRADAY_FACTOR
   C = EXP(MU + SIGMA * qnorm(shading_cap_percentile))
   F = bid_interno * (1 - fee_percentage)
   BPP real replay = MIN(O, C, F)

   Counterfactual scenarios:
   bpp_no_cap      = MIN(O, F)
   bpp_fair_capped = MIN(O, C * SITE_INTRADAY_FACTOR, F)

   `bid_internal` is reconstructed as LEAST(`bids.$.score`, bid_ceiling). The
   observed `bids.$.local` equals the post-shading bid with fee in OLV and must
   not be used as the independent fee ceiling.

   Prints perdidos: filas LOSS con shading_cap_percentile IS NOT NULL cuyo BPP
   contrafactual (no-cap o fair-capped) hubiera superado el FIRST_PRICE.

   qnorm via Abramowitz-Stegun 26.2.17, factorizado en CREATE TEMP FUNCTION
   (mismo patrón que wiki/olv_bidder_cap_bug_evidence_mlb.sql). */

CREATE TEMP FUNCTION qnorm_approx(p FLOAT64) AS (
    CASE
        WHEN p IS NULL OR p <= 0 OR p >= 1 THEN NULL
        WHEN p >= 0.5 THEN
            SQRT(-2.0 * LN(1.0 - p))
            - (2.515517 + 0.802853 * SQRT(-2.0 * LN(1.0 - p)) + 0.010328 * POW(SQRT(-2.0 * LN(1.0 - p)), 2))
              / (1.0 + 1.432788 * SQRT(-2.0 * LN(1.0 - p)) + 0.189269 * POW(SQRT(-2.0 * LN(1.0 - p)), 2)
                     + 0.001308 * POW(SQRT(-2.0 * LN(1.0 - p)), 3))
        ELSE
            -1.0 * (
                SQRT(-2.0 * LN(p))
                - (2.515517 + 0.802853 * SQRT(-2.0 * LN(p)) + 0.010328 * POW(SQRT(-2.0 * LN(p)), 2))
                  / (1.0 + 1.432788 * SQRT(-2.0 * LN(p)) + 0.189269 * POW(SQRT(-2.0 * LN(p)), 2)
                         + 0.001308 * POW(SQRT(-2.0 * LN(p)), 3))
            )
    END
);

/* ── Base: PRINT/LOSS y precios ya resueltos por el ETL fixeado ──────────────
   DEDUP: BID_ID no es único en esta tabla — verificado (ver conversación): 3.598.339
   filas duplicadas (~3.77%) en esta ventana, de las cuales 580.410 (16.1% de los
   duplicados) tienen REASON_NAME_TYPE en conflicto (mismo bid_id aparece como PRINT
   en una fila y LOSS en otra). Consistente con FEEDBACK_DATETIME "llega en el
   siguiente ciclo de subasta" (ver wiki/schemas/BT_ADS_DSP_ADX_PRICING_RAW.md): el
   ETL emite una fila por ciclo de feedback. Nos quedamos con el feedback más
   reciente por BID_ID como clasificación final. BID_PRICE_PARTNER nunca difiere
   entre duplicados (0 conflictos) — solo la clasificación PRINT/LOSS y FIRST_PRICE. */
raw_pricing_dedup AS (
    SELECT
        r.BID_ID                                                     AS bid_id,
        r.LINE_ITEM_ID                                               AS line_item_id,
        r.SIT_SITE_ID                                                AS sit_site_id,
        r.AUCTION_DATETIME_LOCAL                                     AS auction_ts_local,
        r.REASON_NAME_TYPE = 'PRINT'                                 AS is_print,
        r.BID_PRICE_PARTNER                                          AS bid_price_partner,
        r.BID_PRICE                                                  AS bid_price,
        r.FIRST_PRICE                                                AS first_price,
        r.SECOND_PRICE                                                AS second_price,
        r.SHADING_MU                                                 AS shading_mu,
        r.SHADING_SGIMA                                               AS shading_sigma,
        r.SITE_INTRADAY_FACTOR                                       AS site_intraday_factor,
        r.FEE_PERCENTAGE                                             AS fee_percentage
    FROM `meli-bi-data.WHOWNER.BT_ADS_DSP_ADX_PRICING_RAW` r
    CROSS JOIN params
    WHERE r.EXECUTION_DATE BETWEEN
            (SELECT raw_partition_start FROM params)
        AND (SELECT raw_partition_end FROM params)
      AND r.SIT_SITE_ID = params.site
      AND r.PAGE        = params.page
      AND r.AUCTION_DATETIME_LOCAL >= params.analysis_start_local
      AND r.AUCTION_DATETIME_LOCAL < params.analysis_end_local
    QUALIFY ROW_NUMBER() OVER (
        PARTITION BY r.BID_ID, r.LINE_ITEM_ID
        ORDER BY
            r.FEEDBACK_DATETIME_UTC DESC NULLS LAST,
            r.AUCTION_DATETIME_UTC DESC NULLS LAST,
            r.BID_PRICE_PARTNER DESC NULLS LAST
    ) = 1
),

raw_pricing AS (
    SELECT *
    FROM raw_pricing_dedup
),

/* ── Cap signals + internal bid from the winning element ────────────────────────
   The cap percentiles are root fields; reconstruct the independent internal bid
   from `score` and the root bid ceiling before applying the fee ceiling.
   DEDUP: bid_id tampoco es único acá — verificado (ver conversación): 77.956 filas
   duplicadas (~1.28%) sobre ~6M filas capeadas en esta ventana. Streaming con
   posible entrega at-least-once. Nos quedamos con la más reciente por _PARTITIONTIME. */
cap_signals AS (
    SELECT
        ba.bid_id,
        CAST(JSON_VALUE(win_bid, '$.line_item_id') AS INT64) AS line_item_id,
        ba.shading_cap_percentile,
        ba.optimal_win_rate,
        ba.shading_mean AS signal_shading_mu,
        ba.shading_std_dev AS signal_shading_sigma,
        ba.site_intraday_factor AS signal_site_intraday_factor,
        CAST(JSON_VALUE(win_bid, '$.local') AS FLOAT64) AS bid_local_observed,
        CAST(JSON_VALUE(win_bid, '$.score') AS FLOAT64) AS bid_score,
        LEAST(CAST(JSON_VALUE(win_bid, '$.score') AS FLOAT64), ba.bid_ceiling) AS bid_internal
    FROM raw_pricing rp
    JOIN `ads-displa-yxim11er7z5-furyid.ads_display_bq_dataset.bid_auction_adx` ba
        ON ba.bid_id = rp.bid_id
    CROSS JOIN UNNEST(JSON_EXTRACT_ARRAY(ba.bids)) AS win_bid
    CROSS JOIN params
    WHERE ba._PARTITIONTIME >= (SELECT signals_partition_start FROM params)
      AND ba._PARTITIONTIME <  (SELECT signals_partition_end FROM params)
      AND ba.site_id = params.site                                    /* cluster: site_id */
      AND ba.page    = params.page                                    /* cluster: page */
      AND JSON_VALUE(win_bid, '$.reason_name') = 'WIN'
      AND CAST(JSON_VALUE(win_bid, '$.line_item_id') AS INT64) = rp.line_item_id
    QUALIFY ROW_NUMBER() OVER (
        PARTITION BY ba.bid_id, CAST(JSON_VALUE(win_bid, '$.line_item_id') AS INT64)
        ORDER BY ba._PARTITIONTIME DESC
    ) = 1
),

base AS (
    SELECT
        rp.* EXCEPT (shading_mu, shading_sigma, site_intraday_factor),
        COALESCE(rp.shading_mu, cs.signal_shading_mu) AS shading_mu,
        COALESCE(rp.shading_sigma, cs.signal_shading_sigma) AS shading_sigma,
        COALESCE(rp.site_intraday_factor, cs.signal_site_intraday_factor) AS site_intraday_factor,
        cs.shading_cap_percentile,
        cs.optimal_win_rate,
        cs.bid_local_observed,
        cs.bid_score,
        cs.bid_internal,
        params.replay_tolerance
    FROM raw_pricing rp
    CROSS JOIN params
    LEFT JOIN cap_signals cs
        ON rp.bid_id = cs.bid_id
       AND rp.line_item_id = cs.line_item_id
),

/* ── Formula candidates and counterfactual scenarios ─────────────────────────── */
with_candidates AS (
    SELECT
        *,
        CASE
            WHEN shading_cap_percentile IS NOT NULL
                 AND optimal_win_rate IS NOT NULL
                 AND shading_mu    IS NOT NULL
                 AND shading_sigma IS NOT NULL
                 AND fee_percentage IS NOT NULL
            THEN EXP(shading_mu + shading_sigma * qnorm_approx(optimal_win_rate)) * site_intraday_factor
        END                                                           AS candidate_optimal,
        CASE
            WHEN shading_cap_percentile IS NOT NULL
                 AND shading_mu    IS NOT NULL
                 AND shading_sigma IS NOT NULL
                 AND fee_percentage IS NOT NULL
            THEN EXP(shading_mu + shading_sigma * 1.6448536269514722)
        END                                                           AS candidate_p95,
        CASE
            WHEN shading_cap_percentile IS NOT NULL
                 AND bid_internal  IS NOT NULL
                 AND fee_percentage IS NOT NULL
            THEN bid_internal * (1 - fee_percentage)
        END                                                           AS candidate_fee
    FROM base
),

with_scenarios AS (
    SELECT
        *,
        CASE
            WHEN shading_cap_percentile IS NULL THEN bid_price_partner
            WHEN candidate_optimal IS NOT NULL
             AND candidate_p95 IS NOT NULL
             AND candidate_fee IS NOT NULL
            THEN LEAST(candidate_optimal, candidate_p95, candidate_fee)
        END                                                           AS bpp_real_replay,
        CASE
            WHEN shading_cap_percentile IS NULL THEN bid_price_partner
            WHEN candidate_optimal IS NOT NULL AND candidate_fee IS NOT NULL
            THEN LEAST(candidate_optimal, candidate_fee)
        END                                                           AS bpp_no_cap,
        CASE
            WHEN shading_cap_percentile IS NULL THEN bid_price_partner
            WHEN candidate_optimal IS NOT NULL
             AND candidate_p95 IS NOT NULL
             AND candidate_fee IS NOT NULL
            THEN LEAST(candidate_optimal,
                       candidate_p95 * site_intraday_factor,
                       candidate_fee)
        END                                                           AS bpp_fair_capped,
        CASE
            WHEN shading_cap_percentile IS NULL THEN 'NOT_CAPPED'
            WHEN candidate_optimal IS NULL
              OR candidate_p95 IS NULL
              OR candidate_fee IS NULL THEN 'INELIGIBLE'
            WHEN candidate_fee <= candidate_optimal
             AND candidate_fee <= candidate_p95 THEN 'FEE'
            WHEN candidate_p95 <= candidate_optimal THEN 'P95'
            ELSE 'OPTIMAL'
        END                                                           AS binding_term
    FROM with_candidates
),

with_replay_check AS (
    SELECT
        *,
        shading_cap_percentile IS NOT NULL
        AND bpp_real_replay IS NOT NULL
        AND ABS(bpp_real_replay - bid_price_partner) <= replay_tolerance
                                                                    AS replay_matches_observed,
        bpp_no_cap IS NOT NULL                                      AS eligible_for_counterfactual
    FROM with_scenarios
),

/* ── CPM contrafactual sin cap: no solo re-precia los prints capeados que ya
   ganamos, sino que también suma al promedio los prints que hoy son LOSS y que
   hubiéramos ganado sin cap (cola pesada de la lognormal) con su propio precio
   contrafactual. Sin esto, el CPM sin cap subestima el efecto: solo repricea el
   ~10% de wins que ya estaban capeados e ignora los ~926k prints "nuevos" caros. */
with_counterfactual_flag AS (
    SELECT
        *,
        (NOT is_print
         AND shading_cap_percentile IS NOT NULL
         AND first_price IS NOT NULL
         AND bpp_no_cap >= first_price)                               AS is_newly_won_no_cap
    FROM with_replay_check
),

/* ── Agregación horaria (una hora local de MLB) ───────────────────────────────── */
hourly_agg AS (
    SELECT
        DATETIME_TRUNC(auction_ts_local, HOUR)                        AS auction_hour_local,
        sit_site_id,
        COUNTIF(is_print)                                             AS empirical_prints,
        COUNTIF(is_print AND eligible_for_counterfactual)             AS counterfactual_eligible_prints,
        COUNTIF(is_print AND shading_cap_percentile IS NOT NULL)      AS capped_wins,
        COUNTIF(NOT is_print)                                         AS total_losses,
        COUNTIF(NOT is_print AND shading_cap_percentile IS NOT NULL)  AS capped_losses,
        COUNTIF(shading_cap_percentile IS NOT NULL)                   AS capped_bids,
        COUNTIF(shading_cap_percentile IS NOT NULL
                AND bpp_real_replay IS NOT NULL)                      AS replay_eligible_capped_bids,
        COUNTIF(replay_matches_observed)                              AS replay_match_capped_bids,
        COUNTIF(shading_cap_percentile IS NOT NULL AND binding_term = 'OPTIMAL') AS optimal_binding_capped_bids,
        COUNTIF(shading_cap_percentile IS NOT NULL AND binding_term = 'P95')     AS p95_binding_capped_bids,
        COUNTIF(shading_cap_percentile IS NOT NULL AND binding_term = 'FEE')     AS fee_binding_capped_bids,
        COUNTIF(NOT is_print
                AND shading_cap_percentile IS NOT NULL
                AND first_price IS NOT NULL
                AND bpp_no_cap IS NOT NULL
                AND bpp_no_cap >= first_price)                        AS lost_prints_no_cap,
        COUNTIF(NOT is_print
                AND shading_cap_percentile IS NOT NULL
                AND first_price IS NOT NULL
                AND bpp_no_cap IS NOT NULL)                           AS eligible_capped_losses_no_cap,
        COUNTIF(NOT is_print
                AND shading_cap_percentile IS NOT NULL
                AND first_price IS NOT NULL
                AND bpp_no_cap IS NOT NULL
                AND bpp_no_cap < first_price)                         AS capped_losses_below_first_price_no_cap,
        COUNTIF(NOT is_print
                AND shading_cap_percentile IS NOT NULL
                AND (first_price IS NULL OR bpp_no_cap IS NULL))      AS ineligible_capped_losses_no_cap,
        COUNTIF(NOT is_print
                AND shading_cap_percentile IS NOT NULL
                AND first_price IS NULL)                              AS capped_losses_missing_first_price,
        COUNTIF(NOT is_print
                AND shading_cap_percentile IS NOT NULL
                AND candidate_optimal IS NULL)                        AS capped_losses_missing_optimal,
        COUNTIF(NOT is_print
                AND shading_cap_percentile IS NOT NULL
                AND optimal_win_rate IS NULL)                         AS capped_losses_missing_optimal_win_rate,
        COUNTIF(NOT is_print
                AND shading_cap_percentile IS NOT NULL
                AND shading_mu IS NULL)                               AS capped_losses_missing_shading_mu,
        COUNTIF(NOT is_print
                AND shading_cap_percentile IS NOT NULL
                AND shading_sigma IS NULL)                            AS capped_losses_missing_shading_sigma,
        COUNTIF(NOT is_print
                AND shading_cap_percentile IS NOT NULL
                AND candidate_fee IS NULL)                            AS capped_losses_missing_fee,
        COUNTIF(NOT is_print
                AND shading_cap_percentile IS NOT NULL
                AND first_price IS NOT NULL
                AND bpp_fair_capped IS NOT NULL
                AND bpp_fair_capped >= first_price)                   AS lost_prints_fair_capped,
        ROUND(SAFE_DIVIDE(SUM(IF(is_print, bid_price_partner, NULL)), COUNTIF(is_print)), 4) AS empirical_cpm_all,
        ROUND(SAFE_DIVIDE(SUM(IF(is_print AND eligible_for_counterfactual, bid_price_partner, NULL)),
                          COUNTIF(is_print AND eligible_for_counterfactual)), 4)             AS empirical_cpm,
        ROUND(SAFE_DIVIDE(SUM(IF(is_print AND bpp_fair_capped IS NOT NULL, bpp_fair_capped, NULL)),
                          COUNTIF(is_print AND bpp_fair_capped IS NOT NULL)), 4)               AS fair_capped_cpm,
        /* Full no-cap counterfactual: reprice current wins and add newly won prints. */
        ROUND(SAFE_DIVIDE(
            COALESCE(SUM(IF(is_print AND eligible_for_counterfactual, bpp_no_cap, NULL)), 0)
              + COALESCE(SUM(IF(is_newly_won_no_cap, bpp_no_cap, NULL)), 0),
            COUNTIF(is_print AND eligible_for_counterfactual) + COUNTIF(is_newly_won_no_cap)
        ), 4)                                                          AS no_cap_cpm
    FROM with_counterfactual_flag
    GROUP BY ALL
)

CREATE TEMP FUNCTION qnorm_approx(p FLOAT64) AS (
    CASE
        WHEN p IS NULL OR p <= 0 OR p >= 1 THEN NULL
        WHEN p >= 0.5 THEN
            SQRT(-2.0 * LN(1.0 - p))
            - (2.515517 + 0.802853 * SQRT(-2.0 * LN(1.0 - p)) + 0.010328 * POW(SQRT(-2.0 * LN(1.0 - p)), 2))
              / (1.0 + 1.432788 * SQRT(-2.0 * LN(1.0 - p)) + 0.189269 * POW(SQRT(-2.0 * LN(1.0 - p)), 2)
                     + 0.001308 * POW(SQRT(-2.0 * LN(1.0 - p)), 3))
        ELSE
            -1.0 * (
                SQRT(-2.0 * LN(p))
                - (2.515517 + 0.802853 * SQRT(-2.0 * LN(p)) + 0.010328 * POW(SQRT(-2.0 * LN(p)), 2))

/* All OLV shading distributions affected by the P95 cap, MLB.
   A distribution is the auction-signals placement, domain, and rounded mu/sigma.
   Signals are the single source of the grouping key for both prints and losses.
   The ranking cohort contains only P95-bound losses that would win with bpp_no_cap.
   The combined counterfactual BPP is weighted across repriced current prints and
   recovered losses; it is not an average of the two cohort averages. */

CREATE TEMP FUNCTION qnorm_approx(p FLOAT64) AS (
    CASE
        WHEN p IS NULL OR p <= 0 OR p >= 1 THEN NULL
        WHEN p >= 0.5 THEN
            SQRT(-2.0 * LN(1.0 - p))
            - (2.515517 + 0.802853 * SQRT(-2.0 * LN(1.0 - p)) + 0.010328 * POW(SQRT(-2.0 * LN(1.0 - p)), 2))
              / (1.0 + 1.432788 * SQRT(-2.0 * LN(1.0 - p)) + 0.189269 * POW(SQRT(-2.0 * LN(1.0 - p)), 2)
                     + 0.001308 * POW(SQRT(-2.0 * LN(1.0 - p)), 3))
        ELSE
            -1.0 * (
                SQRT(-2.0 * LN(p))
                - (2.515517 + 0.802853 * SQRT(-2.0 * LN(p)) + 0.010328 * POW(SQRT(-2.0 * LN(p)), 2))
                  / (1.0 + 1.432788 * SQRT(-2.0 * LN(p)) + 0.189269 * POW(SQRT(-2.0 * LN(p)), 2)
                         + 0.001308 * POW(SQRT(-2.0 * LN(p)), 3))
            )
    END
);

        DATE(TIMESTAMP(DATETIME_SUB(analysis_end_local, INTERVAL 1 MICROSECOND), tz), 'Etc/GMT+4') AS raw_partition_end,

        s.signal_domain AS curve_domain,
        ROUND(s.signal_shading_mu, 6) AS curve_shading_mu,
        ROUND(s.signal_shading_sigma, 6) AS curve_shading_sigma

affected_distributions AS (

        curve_placement,
        curve_domain,
        curve_shading_mu,
        curve_shading_sigma,
        COUNTIF(NOT is_print AND binding_term = 'P95' AND first_price IS NOT NULL AND bpp_no_cap >= first_price) AS lost_prints_no_cap
    FROM scenarios
    WHERE shading_cap_percentile IS NOT NULL
      AND binding_term = 'P95'
      AND curve_shading_mu IS NOT NULL
      AND curve_shading_sigma IS NOT NULL
    GROUP BY ALL

distribution_metrics AS (
    SELECT
        s.curve_placement,
        s.curve_domain,
        s.curve_shading_mu,
        s.curve_shading_sigma,
        COUNT(*) AS total_bids_curve,
        COUNTIF(s.is_print) AS empirical_prints_total_curve,
        COUNTIF(s.is_print AND s.binding_term = 'P95') AS empirical_prints_p95_binding,
        COUNTIF(NOT s.is_print AND s.binding_term = 'P95') AS p95_binding_losses,
        COUNTIF(NOT s.is_print AND s.binding_term = 'P95' AND s.first_price IS NOT NULL AND s.bpp_no_cap >= s.first_price) AS lost_prints_no_cap,
        AVG(IF(s.is_print, s.observed_bpp, NULL)) AS empirical_print_bpp_avg,
        APPROX_QUANTILES(IF(s.is_print, s.observed_bpp, NULL), 100)[OFFSET(50)] AS empirical_print_bpp_p50,
        APPROX_QUANTILES(IF(s.is_print, s.observed_bpp, NULL), 100)[OFFSET(90)] AS empirical_print_bpp_p90,
        AVG(IF(s.is_print, s.bpp_no_cap, NULL)) AS repriced_prints_bpp_no_cap,
        AVG(IF(NOT s.is_print AND s.first_price IS NOT NULL AND s.bpp_no_cap >= s.first_price, s.bpp_no_cap, NULL)) AS recovered_losses_bpp_no_cap,
        SAFE_DIVIDE(
            SUM(IF(s.is_print OR (NOT s.is_print AND s.first_price IS NOT NULL AND s.bpp_no_cap >= s.first_price), s.bpp_no_cap, NULL)),
            COUNTIF(s.is_print OR (NOT s.is_print AND s.first_price IS NOT NULL AND s.bpp_no_cap >= s.first_price))
        ) AS counterfactual_bpp_no_cap
    FROM scenarios s
    JOIN affected_distributions d
        ON s.curve_placement IS NOT DISTINCT FROM d.curve_placement
       AND s.curve_domain IS NOT DISTINCT FROM d.curve_domain
       AND s.curve_shading_mu = d.curve_shading_mu
       AND s.curve_shading_sigma = d.curve_shading_sigma
    GROUP BY ALL
)

SELECT
    curve_placement AS placement,
    curve_domain AS domain,
    curve_shading_mu AS shading_mu,
    curve_shading_sigma AS shading_sigma,
    total_bids_curve,
    empirical_prints_total_curve,
    empirical_prints_p95_binding,
    p95_binding_losses,
    lost_prints_no_cap,
    ROUND(SAFE_DIVIDE(lost_prints_no_cap, empirical_prints_total_curve + lost_prints_no_cap) * 100, 2) AS pct_prints_lost_no_cap,
    ROUND(empirical_print_bpp_avg, 4) AS empirical_print_bpp_avg,
    ROUND(empirical_print_bpp_p50, 4) AS empirical_print_bpp_p50,
    ROUND(empirical_print_bpp_p90, 4) AS empirical_print_bpp_p90,
    ROUND(repriced_prints_bpp_no_cap, 4) AS repriced_prints_bpp_no_cap,
    ROUND(recovered_losses_bpp_no_cap, 4) AS recovered_losses_bpp_no_cap,
    ROUND(counterfactual_bpp_no_cap, 4) AS counterfactual_bpp_no_cap
FROM distribution_metrics
ORDER BY lost_prints_no_cap DESC, placement, domain, shading_mu, shading_sigma
